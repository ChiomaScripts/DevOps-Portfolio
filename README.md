## Engineering Focus

The projects in this portfolio are organised around the following engineering disciplines:

- **Cloud Infrastructure:** Provisioning, configuring, and managing cloud-hosted environments.
- **Linux & Systems Administration:** User management, SSH authentication, filesystem permissions, and server configuration.
- **Application Deployment:** Building, packaging, transferring, executing, and verifying applications.
- **DevOps Automation:** Developing repeatable processes and reducing manual operational tasks.
- **CI/CD & Infrastructure as Code:** Building skills in automated delivery pipelines and declarative infrastructure management.
- **Observability & Reliability:** Exploring application monitoring, troubleshooting, and operational reliability.
